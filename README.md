# AutoConX — Vehicle Inspection Booking App

AutoConX is a React Native mobile application built with Expo and TypeScript. It allows users to browse vehicles, select a vehicle for inspection, schedule an inspection, and review booking details through a simple, user-friendly interface.

## Features

- **Vehicle Listing:** Browse five vehicles with images, model years, and body types.
- **Vehicle Selection:** Start the booking process for a selected vehicle.
- **Inspection Booking:** Choose an inspection type, enter an address, select a date, and add optional notes.
- **Current Location Support:** Use device location to help determine the inspection address.
- **Date Validation:** Prevent selecting past inspection dates.
- **Draft Persistence:** Save and restore booking form data using AsyncStorage.
- **Booking Confirmation:** Display the submission status and booking reference.
- **Booking Details:** Review the selected vehicle and booking information.
- **Pull-to-Refresh:** Refresh the vehicle listing interface.
- **Navigation:** Navigate between vehicle listing, booking, confirmation, and booking details screens.

## Screens

1. **My Vehicle** — Browse the available vehicles.
2. **Book Inspection** — Enter inspection preferences and booking details.
3. **Confirmation** — View the booking submission status.
4. **Booking Details** — Review the booking summary.

## Prerequisites

- Node.js and npm
- Expo Go for compatible physical-device testing
- An Expo account for EAS cloud builds

## Installation

Clone the repository:

```bash
git clone https://github.com/singhyashdevops/autoconx-rn-assessment.git
cd autoconx-rn-assessment
```

Install dependencies:

```bash
npm install
```

## Run the Application

Start the Expo development server:

```bash
npx expo start
```

Scan the QR code using Expo Go on a compatible device, or use the available emulator options.

## Build an Android APK

Build an Android APK using the configured `preview` profile:

```bash
npx eas-cli@latest build --platform android --profile preview
```

Once the cloud build completes, download the APK from the EAS build page and install it on a compatible Android device.

## Booking Workflow

1. Browse the available vehicles.
2. Select **Book** for the desired vehicle.
3. Choose an inspection type.
4. Enter the inspection address.
5. Select an inspection date and add optional notes.
6. Submit the booking.
7. Review the confirmation and booking details.

## Data and API Notes

The current implementation uses local vehicle data and a mock booking submission flow to demonstrate the application workflow.

- Booking submission is not connected to a production backend.
- Server-side booking persistence is not implemented.
- Confirmation status and booking references are generated by the mock implementation and do not represent a guaranteed real-world booking.
- Booking form drafts are stored locally using AsyncStorage.
