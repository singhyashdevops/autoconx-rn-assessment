# AutoConX — Vehicle Inspection Booking App

AutoConX is a React Native mobile application built with Expo that allows users to select a vehicle, schedule a professional vehicle inspection, and review their booking details.

## Features

- **Vehicle Listing:** Browse five vehicles with images, model years, and body types.
- **Vehicle Selection:** Select a vehicle to begin the inspection booking process.
- **Inspection Booking:** Choose an inspection type, enter an address, select a date, and add optional notes.
- **Location Support:** Use the device's current location to help fill in the inspection address.
- **Date Validation:** Prevent selecting past dates for inspections.
- **Draft Persistence:** Save and restore booking form data locally.
- **Booking Confirmation:** Display the booking status and reference information.
- **Booking Details:** Review the selected vehicle and submitted booking information.
- **Pull-to-Refresh:** Refresh the vehicle listing interface.
- **Reusable UI:** Consistent styling and reusable React Native components.

## Screens

1. **My Vehicle** — Browse available vehicles.
2. **Book Inspection** — Enter inspection preferences and booking details.
3. **Confirmation** — View the booking submission status.
4. **Booking Details** — Review the booking summary.

## Prerequisites

Install the following before running the project:

- Node.js and npm
- Expo Go for testing on a physical device
- Expo account for cloud builds

## Installation

Clone the repository and navigate to the project directory:

```bash
git clone <YOUR_REPOSITORY_URL>
cd autoconx-rn-assessment
```

Install dependencies:

```bash
npm install
```

If dependency conflicts occur, review the package requirements before using any legacy peer-dependency options.

## Run the Application

Start the Expo development server:

```bash
npx expo start
```

Scan the QR code using Expo Go to run the application on a compatible device.

## Build an Android APK

The project uses Expo Application Services (EAS) for cloud builds.

Install or invoke the EAS CLI:

```bash
npx eas-cli@latest build:configure
```

Build an Android APK using the `preview` profile:

```bash
npx eas-cli@latest build --platform android --profile preview
```

After the build completes, download the APK from the build page and install it on a compatible Android device.

## Booking Workflow

1. Browse the available vehicles.
2. Select **Book** for the desired vehicle.
3. Choose an inspection type.
4. Enter the inspection address and select a date.
5. Add optional notes.
6. Submit the booking.
7. Review the confirmation and booking details.

## Data and API Notes

The current project includes a mock booking API for demonstrating the booking workflow. Booking references and confirmation states are generated by the mock implementation.

- Vehicle data is currently provided locally.
- Booking submission is not connected to a production backend.
- Persistent server-side booking storage is not implemented.
- The displayed confirmation status should not be treated as a real-world booking guarantee.
